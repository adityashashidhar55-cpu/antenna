Monthly Trend Reports

A monthly digest, built from the same live data

Antenna's monthly report isn't a separately-researched publication — it's a structured pull from the same trend data tracked on the dashboard, packaged into a readable monthly snapshot for India & France.

What's in the monthly report

Each edition is organized around the same categories and momentum states you'd see filtering the live dashboard yourself.

🚀

Top breakout trends

The trends that moved into "Exploding" status that month, per market, pulled directly from stored trend snapshots — not a curated top-10 list assembled by hand.

🌍

Regional split

A side-by-side read on how India and France's tracked categories differed that month, based on the same country tags used in the dashboard filters.

🧵

Source mix

Which channels — Hacker News, dev.to, Product Hunt, Reddit — were driving the month's signal, so the report stays traceable back to real activity.

How it's built — honestly

No separate research team writing this from scratch each month. Here's exactly what goes into it.

📡

Pulled from stored data

Trend names, scores, momentum status and source counts come straight from Antenna's stored trend data — the same records the dashboard reads from.

🤖

AI-written commentary, labeled

Any narrative summary or "why now" framing is AI-generated from the underlying data and marked as an AI-estimated summary, not a human analyst's independent research.

🕒

A monthly cadence

Compiled roughly once a month as a snapshot in time — a between-checks summary, not a substitute for watching the live dashboard for anything time-sensitive.
