System Status

This page makes a real, live network request to each backend endpoint straight from your browser when it loads — the pills below reflect what actually happened just now, not a hardcoded claim.

Checking live status…
Running checks in your browser

These checks call the same public, read-only n8n API endpoints Antenna's dashboard uses for live trend, product, and startup data. Each check uses a 6-second timeout — if an endpoint doesn't respond successfully within that window (or the request errors out, including due to network issues or an ad-blocker), it's shown as Degraded or Down below.

Operational — responded successfully Degraded — slow, or returned an error status Down — timed out or failed to respond
About the frontend: Antenna's dashboard and marketing pages are static files served over HTTPS via GitHub Pages. If you're able to load this page at all, static hosting is serving normally — there's no separate "frontend status" to poll, since a failure there would mean this page itself wouldn't load.
